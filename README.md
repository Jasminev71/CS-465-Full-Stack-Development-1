## CS 465 Reflection

This course focused on developing a full stack web application using the MEAN stack, which consists of MongoDB, Express, Angular, and Node.js. The front end utilizes express to render for the ui/ux pages, while the backend utilizes angular to deliver a more dynamic interface. The SPA improved the UI by utilizing navigation and updates without needing a full page reload. As for the backend using MongoDB enabled the application to be flexible as the structure works well with JSON da ta and integrates smoothly with JS and Mongoose. 
	JSON is a huge part in connecting the front end and back end, while JS is used to program the application, Json is used as the data format. That allows for information to be transmitted between Angular client and Express API. Throughout this course, refactoring was essential for improving organization and efficiency. This help to reduce duplication and improve the app maintainability, and also having reusable UI components was a plus.
	For testing it was essential for verify that the SPA was communicating properly with the backend API. By using GET and PUT endpoints it ensured	that trip data could be retrieved  correctly in MongoDB. I did consider the role of authentication and secure route access when creating  the user login features. 
	This course was essential as it helped to strengthen my understanding of what full stack really is and developing and deploying a complete web application. I am excited to learn different stacks in the future and what I can expect going forward.
